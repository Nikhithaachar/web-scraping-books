# web-scraping-books
web scrapping project to extract book data ( title ,price, rating ) using python
Web Scraping Books Project

Description

This project extracts book data such as title, price, and rating from an e-commerce website using Python.

Tasks Performed

- Sent HTTP request to website
- Parsed HTML using BeautifulSoup
- Extracted book details (title, price, rating)
- Used loops to scrape multiple records
- Created a structured DataFrame
- Saved data into CSV file

Tools Used

- Python
- Requests
- BeautifulSoup
- Pandas

Website Used

https://books.toscrape.com/

Output

Scraped data saved in CSV format
